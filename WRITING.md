# Report writing rules

Use Simplified Technical English as the writing style for the current report.

- Write short sentences. Aim for 20 words or fewer in normal prose.
- Put one main idea in each sentence. Use the active voice when the subject is known.
- Use one term for one meaning. Define a technical term before you use it.
- Use exact dates and units. Separate a count from a rate.
- State what the data measures. Separate an observation from a cause.
- Keep facts, formulas, links, data keys and matching rules unchanged during a copy edit.
- Keep source quotations and issue titles unchanged. Label preserved source text clearly.
- Treat the archive as source evidence. Apply these rules to current explanations and navigation.

| Term | Meaning in this report |
| --- | --- |
| Report | A GitHub issue that passes the possible-bug filter. It is not a confirmed defect. |
| npm request | A download request for the npm package `bun`. It is not a user count. |
| Report group | Reports opened within a stated period. This does not assign a language. |
| Canary period | The dates between merge and Rust stable. Stable remained on Zig. |
| Version family | A Zig-line, Rust-line, or unclear inference from stated version text. It is not a binary check. |
| Title match | A word pattern found in the issue title. It is not a root-cause check. |
| Period rate | Total reports divided by total npm requests for the same complete days. |
| Before-merge reference | The daily mean or period rate before 14 May 2026, as labelled. |
| Growth index | A daily mean divided by its before-merge mean, then multiplied by 100. |
| Relative report rate | The report growth index divided by the npm growth index. The reference is 1. |
| Extra body-text check | A second calculation that adds up to 2,500 body characters. It checks sensitivity to text selection. |
| Marked as fixed | GitHub currently records the issue as `closed` with reason `completed`. |

The matching rules use technical names from Bun and GitHub. Do not change those names or source evidence to meet a vocabulary target.
